## 3. 可靠結論(給動畫用)

- 貓絕大多數時間靜止:躺+坐 ~74%,站 ~13%,真正「活躍」(跑跳玩)約 3%。**懶貓設定是寫實的**。
- 理毛、進食、排泄各占約 1-2% 或更少,屬於偶發小插曲。
- 進食頻率約 6-7 餐/天以上,排泄約 3 次/天、每次約 1 分鐘:動畫若要演,頻率非常低即可。
- 活動集中在晨昏(及餵食時間前後)。

## 4. 動畫參數建議

### 4.1 壓縮規則

1. **保留比例,縮短絕對時間**:真實 bout 以分鐘到小時計,動畫把「靜止類」姿勢的停留壓縮到 15-90 秒,「動作類」維持接近真實的秒數(動作一旦過慢就不自然)。
2. **靜止類設上限**:睡/loaf/坐等長停留一律 cap 在 90 秒,並加隨機 jitter ±30%。
3. **動作類不縮短**:伸展、理毛、走路用真實秒數(5-20 秒),所以動作類在動畫中的「時間占比」會比真實高;用較低的選擇權重補償。
4. **權重 = 真實時間占比 / 平均停留時間,再以偏好調整**(此處用較直覺的調整後數值)。
5. 轉場一律 ≥1.2 秒緩動,不瞬切。

### 4.2 姿勢權重與停留

姿勢細分(ball / loaf / 側躺 / 坐)沒有量測資料;下表是把「躺 ~37% + 坐 ~37% + 站 ~13% + 活動 ~3%」往細分姿勢分配的**推論**,並依「懶貓、少動」偏好調整。

| 姿勢 | 選擇權重(%) | 停留(秒) | 備註 |
|---|---|---|---|
| 蜷縮睡 (ball) | 28 | 40-90 | 最常見的睡姿,可偶爾 Z 氣泡;[推論] |
| 趴窩 (loaf) | 20 | 25-70 | 清醒休息,可配慢眨眼 |
| 坐直 (sit) | 15 | 15-50 | 可配耳朵抖、轉頭 |
| 側躺 | 13 | 30-80 | 放鬆睡姿 |
| 翻肚 (belly-up) | 3 | 6-15 | 短暫、放鬆;只能從側躺進入,不從 sit |
| 伸展 | 4 | 4-8 | 只接在睡姿(ball/側躺/loaf)之後 |
| 理毛 | 8 | 8-25 | 臉部 ~50%,其餘為側腹/後肢/腹部(理毛部位比例見 #2);單次分段可 <60 秒 |
| 走 | 4 | 4-12 | 慢走,單次距離短 |

| 貓砂盆 | 0.5 | 15-40(含挖砂 3-8 秒) | 週期一次;真實 ~1 分鐘/次、3 次/天 |
| 抓 | 1 | 5-12 | 睡醒後優先 |
| 踏踏 | 1.5 | 8-20 | 從側躺/loaf 轉入;[缺口]無量測 |
| 玩 | 0.5 | 6-15 | |
| 跑 | 0.3 | 1.5-3 | 極罕見;跑完強制回 sit 或 loaf |
| 哈欠 | 疊加動畫 | 2.5-4 | 不當作獨立姿勢,在睡醒後或 sit 時以 3% 機率疊加 |
| 眨眼 / 耳朵抖 | 疊加動畫 | 0.3 / 0.5 | loaf、sit 時週期性疊加(如每 6-15 秒隨機) |

權重合計約 100.3,實作時請正規化。

### 4.3 轉場規則

- 睡姿(ball/側躺/loaf)→ 下一狀態:有 35-50% 機率先插入「伸展」(+ 可疊加哈欠),才進入 sit/理毛/走。
- 伸展 → 理毛(30%)、sit(35%)、走(20%)、抓(10%)、loaf(5%)。
- 理毛 前後:接 sit 或 loaf 為主;理毛結束後偏向轉睡姿(約 50%)。
- 進食 → 理毛(40%)→ 睡姿(約 45%)。
- 走 → sit / loaf / 進食 / 貓砂盆 / 抓;走完不直接跑。
- 跑 → 只能由「走」或「玩」進入;結束必回 sit/loaf。
- 翻肚 → 只能由側躺進入、只能回側躺。
- 單次不直接重複同一姿勢;連續同類(睡姿到睡姿)允許但轉場要慢(≥1.5 秒)。
- 時段(可選):晨昏窗口(例如 07-09、17-19)把「走/玩/進食/抓」權重 ×1.5-2,睡姿權重 ×0.7;其他時段反向。若是「閒置」儀表板,可用 agent 忙碌/空閒狀態取代時鐘。
- 懶貓偏好:任何非睡姿的「動作類」連續出現不超過 2 次,第三次強制接靜止類。
